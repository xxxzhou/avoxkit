# Avoxkit 功能说明

> 免费、本地、无账号的桌面音视频工具箱  
> 当前版本 0.1.0 · Windows 64 位 / macOS arm64 桌面版

Avoxkit 把日常最常用的音视频处理放进一个窗口：转换格式、录屏、截取片段、提取音频、提取字幕、修复图片水印。它不需要登录，没有会员等级，也不会在产物上加水印；所有媒体处理都在本机完成，文件不会上传。

它面向常规音视频处理：把这个文件处理成我要的样子，或把屏幕录成一段带包装的成片，而不是做多轨剪辑和复杂创作。

## 三句话

- **免费**：所有功能免费，没有会员、没有水印。
- **本地**：媒体文件只在这台电脑上处理，不会上传到任何服务器。
- **无账号**：不需要注册、登录，也不收集使用数据。

## 功能一览

| 功能 | 能做什么 | 输入 | 输出 |
|---|---|---|---|
| 转换 | 改容器、视频编码、分辨率、音频编码；只换容器时自动直接封装 | 单个文件或整个文件夹 | MP4 / MKV / MOV 等 |
| 录屏 | 录制显示器或屏幕区域，可同时录麦克风和系统声音（系统声音目前仅 Windows）；停止后可导出带背景、圆角、阴影的成片 | 显示器 / 区域 | MP4 + 原始录制素材 |
| 截取片段 | 在时间线上选出起止点，保存其中一段 | 单个文件 | 重新编码的片段 |
| 提取音频 | 从视频中导出音轨 | 单个文件或整个文件夹 | M4A / MP3 / 原始音轨 |
| 提取字幕 | 导出内嵌文本字幕，或用本地语音识别生成 SRT | 单个文件或整个文件夹 | SRT |
| 图像修复 | 自动识别或手动涂抹，去除图片里的水印、台标和文字 | 单张图片或整个文件夹 | JPG / PNG / BMP / TGA |
| 任务中心 | 查看进度、排队位置、批量组；取消、重试失败项、打开产物 | — | — |

## 转换

一个入口同时完成“格式转换”和“封装转换”（只换文件外壳，不重新编码）。默认所有设置都跟随源文件；只有输出容器、视频编码、分辨率或音频编码与源文件不一致时，才会产生处理任务。

### 输出设置

| 项目 | 可选值 |
|---|---|
| 容器（文件格式） | 同源、MP4、MKV、MOV |
| 视频编码 | 同源、H.264、H.265 |
| 分辨率 | 同源、2160p、1440p、1080p、720p、480p |
| 音频编码 | 同源、AAC、MP3 |
| 音频码率 | 自动、128、192、256 kbps（音频需要重编码时出现） |
| 质量 | 0–100，数值越大越清晰、文件越大 |
| 硬件编码 | 可选；本机检测到可用硬件编码器时可开启，否则开关不可用；默认使用软件编码 |

分辨率按源画面比例缩放，只指定目标高度；放大画面时会提示。

页面上还有两个快捷设置：

- **仅换容器 MP4**：优先视频和音频直拷；源编码不被 MP4 支持时会自动转码并提示。
- **H.265 · 1080p**：优先使用 H.265；本机没有 H.265 编码器时回退 H.264。

### 自动判定

提交前会逐文件比较源流和目标设置，自动决定怎么处理：

| 情况 | 处理方式 |
|---|---|
| 只改容器，编码和分辨率不变，且目标容器支持源编码 | 直接封装，不重新编码 |
| 改视频编码或分辨率 | 重新编码视频；音频能直拷就直拷 |
| 只改音频编码 | 视频直拷，音频重新编码 |
| 设置与源文件完全一致 | 提示无需转换，不产生任务 |
| 目标容器装不下源编码 | 提示更换容器或编码；能转换时使用可用的编码 |
| 输入和输出指向同一个文件 | 拒绝提交，避免覆盖源文件 |

直接封装仍然需要完整读写文件，只是不做编解码；云盘、机械盘或网络位置会受磁盘速度限制，并不等于“瞬间完成”。

如果 MP4 里保留 HEVC/AV1 视频，或保留 E-AC-3、AC-3、ALAC 等旧式多声道音频，界面会提示 Windows 自带播放器可能打不开；这不是产物损坏，换用支持该编码的播放器即可。

### 文件夹批量

转换页可以直接选择整个文件夹：

- 默认包含子文件夹，可关闭。
- 按相对路径自然排序，集数顺序稳定，例如“第 2 集”排在“第 10 集”前面。
- 默认跳过已存在的输出，以及本工具上次生成的产物。
- 支持三种输出位置：源文件旁、输出目录并保留子目录结构、输出目录平铺。
- 提交前显示匹配数量和总大小；扫描结果在提交时固定，之后新增的文件不会自动加入。
- 一次最多扫描 5000 个文件，超过时停止扫描并提示缩小范围。
- 单个文件无法读取或无需转换时不会阻塞其他文件；提交后会汇总封装、转码、跳过、无法处理和被拒绝的数量。

支持的源文件扩展名：mkv、mp4、mov、avi、ts、flv、webm、wmv、m4v。

## 录屏

把显示器画面录成视频，可同时录麦克风和系统声音（macOS 目前仅支持麦克风）。录制和导出都在本机完成，文件不会上传。

### 录制

- 选择显示器，或从显示器左上角起录一个固定区域（宽高需为偶数像素）。
- 帧率可选 30 或 60 fps。
- 麦克风和系统声音分别开关；没有对应声源时会跳过。
- “录下系统光标”默认关闭：光标不会烧进原始画面，导出时按轨迹重绘；打开后光标直接录进画面。
- 每次录制在输出目录下按时间新建文件夹，保留原始画面、带混音的预览成片和工程文件，方便重复导出。
- 录制期间本应用窗口会从画面中排除。

### 导出成片

- 停止录制后可以导出 H.264 + AAC 的 MP4。
- 默认包装：深色渐变背景、留白、圆角、阴影；横屏输出 1920×1080，竖屏源输出 1080×1920，方形源输出 1080×1080。
- 关闭“录下系统光标”时，导出会按录下的光标位置重绘光标。
- 当前使用固定包装，暂不支持缩放、裁剪、分段或自定义背景/圆角/阴影。

### 边界

- 系统声音来自声卡回环（目前仅 Windows）；macOS 下系统声音开关不可用，系统静音或没有播放声音时也不会产生音轨。
- 录制区域内的所有窗口都会被录进画面，注意遮挡。
- 当前没有摄像头画中画。

## 截取片段

从视频中取出一段单独保存。截取只处理单个文件，不接受文件夹。

### 时间线

截取页的主体是一条“区间尺”，不是播放器：

- 缩略图条按整片均匀采样，铺在时间线上。
- 有音轨时显示音频包络；没有音轨时只显示时间刻度，不影响选点。
- 关键帧用短刻度标出。
- 两个手柄定义入点和出点；拖动时上方画面参考会跟随显示对应时刻。
- 滚轮以指针为锚缩放，拖空白处平移，双击回到全片。
- 开始/结束时间也可以直接输入，支持 `hh:mm:ss.mmm`、`mm:ss` 和秒数；输入框与时间线始终同步。
- 拖动时先用最近缓存的画面，停稳后再抓取精确帧；不做逐帧连续预览。

起点会吸附到目标前最近的关键帧，这样界面显示的时间就是产物的真实起点。起点必须落在片长前 90% 以内；终点按时间截断，受编码和写入进度影响，可能有半秒内偏差。

### 输出

- 片段会重新编码，**不是无损剪切**。
- 视频编码为 H.264 或 H.265，音频为 AAC。
- 容器可选同源、MP4、MKV、MOV。
- 质量 0–100 可调。
- 默认输出到源文件旁，文件名形如 `原文件名.clip.mp4`。
- 最短片段 0.1 秒。

## 提取音频

把一个或一整个文件夹里的视频音轨单独导出。

### 输出格式

| 格式 | 说明 |
|---|---|
| M4A | AAC 音频，兼容性好；会按码率重新编码 |
| MP3 | 通用性最强；会按码率重新编码 |
| 原始音轨 | 不重新编码，速度最快；目标容器不接受该编码时会自动重编码 |

- M4A / MP3 可选 128、192、256、320 kbps。
- 原始音轨只支持单文件；文件夹批量导出提供 M4A 和 MP3。
- 按文件的第一条音轨导出。
- 没有音轨的文件会在提交时被拒绝；批量时不影响其他文件。
- 输出默认放在源文件旁；文件夹模式支持源文件旁、保留子目录结构、平铺三种位置。
- 默认不覆盖已有文件；批量导出时，已存在的输出会跳过。

## 提取字幕

有内嵌文本字幕轨时直接导出 SRT；没有时可以用本地语音识别生成。文件不会上传。

### 内嵌字幕

- 自动选择默认文本轨；没有默认轨时优先中文，再退回第一条文本字幕。
- 也可以手动选择具体字幕轨。
- 支持 SRT、ASS/SSA、WebVTT、mov_text 等常见文本字幕轨。
- PGS、DVD、DVB 等图形字幕不能直接导出为文字，界面会明确提示，并建议改用语音识别。
- 输出为同名 `.srt` 文件，默认放在源文件旁。
- 批量提交时逐文件探测：有文本字幕轨就导出，没有时才按需识别；已存在的同名 `.srt` 会跳过。

### 本地语音识别

- 使用 SenseVoice + Silero VAD，在本机完成识别，不上传音频。
- 支持中文、英文、日文、韩文、粤语。
- 识别模型不随安装包分发；首次使用时按需下载，约 230 MB，带 SHA-256 校验。
- 下载完成后即可离线识别；不识别不会下载。
- 单个文件和文件夹批量都支持。批量时会先逐个探测，分别统计“内嵌导出”和“语音识别”的数量。
- 输出为 `.srt`，默认与源文件同名、放在源文件旁。

## 图像修复

从图片里去掉水印、台标和叠加文字。两种方式：

- **自动识别**：先在本机识别可疑水印位置，再用图像修复模型补全背景；适合水印位置不固定的图片。
- **手动涂抹**：在预览图上涂出要移除的区域，只修复涂抹部分；适合已知位置的台标、角标或文字。

### 使用方式

- 支持单张图片，也支持整个文件夹批量处理。
- 批量统一走自动识别：每张图独立检测，识别不到水印的图片会跳过并在任务里标记。
- 手动涂抹只对单张生效，不套用到整个文件夹。
- 涂抹时可以调笔刷大小、撤销和清空；涂抹区域以原图像素生成修复掩码。
- 自动识别结果会用框标在预览图上；也可以不先识别，直接开始修复（任务内部会自动识别）。
- 修复完成后预览会切到结果图，可以随时切回原图对比。

### 支持格式

- 输入：JPG、JPEG、PNG、BMP、WebP、TGA。
- 输出：JPG、PNG、BMP、TGA；选择“保持原格式”时跟随源文件，WebP 输入会输出 PNG。
- 输出默认放在源文件旁，文件名加 `-repaired`；文件夹模式支持源文件旁、保留子目录结构、平铺三种位置。
- 重复修复会直接覆盖同名的 `-repaired` 文件，不需要先手动删除上一次结果。

### 模型

- 使用 LaMa 图像修复模型和 YOLO26-Seg 水印分割模型，在本机完成检测和修复，不上传图片。
- 模型不随安装包分发；首次使用时按需下载，约 290 MB，带 SHA-256 校验。
- 下载完成后即可离线使用；不使用图像修复不会下载。

### 效果边界

- 自动识别针对常见文字水印、台标和角标；半透明、大面积或背景复杂的区域可能识别不到或修复不干净，此时改用手动涂抹。
- 修复是生成式补全，不保证与原背景完全一致；重要图片建议保留原图。
- 单张图片越大，模型推理越慢；超大图会自动分块处理。

## 任务、队列与批量

所有工具共用同一个任务队列和任务页。

- 默认一次处理一个任务，避免多个编码器同时争抢 GPU 和磁盘。
- 排队中的任务显示“前面还有 N 个”；开始后显示阶段和百分比。
- 处理中的任务可以取消；取消后不会保留未完成的临时产物。
- 批量任务以组为单位显示：总数、完成、失败、进行中、排队和跳过数量。
- 批量组可以整组取消，也可以一键重试失败项。
- 任务详情页可以查看来源、输出、类型、任务号，以及失败原因和日志入口。
- 已完成的任务可以直接打开输出文件夹；产物路径支持双击复制。

### 处理中预览

- Windows 版在需要重新编码视频的转码任务运行中，会在工具页的任务卡或任务详情页显示正在处理的画面；截取片段在任务详情页显示画面。
- 需要重新编码音频的提取任务和转换任务，会显示实时音频包络（波形）。
- 完全直拷（封装或原始音轨导出）没有可显示的画面或音频数据，因此只显示进度；视频直拷但音频重编码的任务仍会显示音频包络。
- 预览只用于确认当前处理内容，不是播放器：没有播放、暂停或连续拖动。

### 输出安全

- 先写临时文件，成功后再替换为最终文件；失败或取消会清理临时文件。
- 默认不覆盖已有文件；批量处理时已存在的输出会跳过。
- 失败任务会显示错误原因、错误码和日志入口，方便定位是源文件、输出路径还是编码问题。

任务队列和历史保存在本次运行内；关闭应用后会清空。需要长期保留的产物请确认已经写入输出目录。

## 隐私与本地处理

- 媒体文件不会上传，也不经过任何云端处理。
- 不需要账号，不收集使用数据，没有广告，没有水印。
- 除首次使用语音识别或图像修复时按需下载模型外，日常转换、截取、提取都不需要联网。
- 模型下载只获取模型文件，不会读取或上传你的媒体文件。
- 应用不包含遥测、云同步或自动上传逻辑。

## 技术底座与许可

Avoxkit 使用 Flutter 构建桌面界面，媒体处理由开源引擎 avox 完成。出厂运行时使用带 x264、x265 和 libmp3lame 的 FFmpeg GPL 构建；语音识别使用 sherpa-onnx，模型为 SenseVoice（Apache-2.0）与 Silero VAD（MIT）。
